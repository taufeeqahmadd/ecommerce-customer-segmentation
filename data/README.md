# Dataset folder

The dataset is **not** stored in this GitHub repository because the file is large.

1. Download **Online Retail** from the UCI Machine Learning Repository:
   https://archive.ics.uci.edu/dataset/352/online+retail
2. Save the file as `Online_Retail.xlsx` inside this `data/` folder.

The notebook reads the file from `data/Online_Retail.xlsx`.
Git ignores everything in this folder except this README, so the dataset will never be uploaded by mistake.
